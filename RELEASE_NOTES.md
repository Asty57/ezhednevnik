# Ежедневник 1.2

Устанавливается поверх прошлой версии — отметки сохраняются. Старую версию удалять НЕ нужно.

## Исправлено / добавлено
- **Уведомления теперь работают по-настоящему.** Приложение создаёт напоминание и каждый день в выбранное время присылает уведомление «Отметьте выполненные работы».
- При первом включении появляется системный запрос — разрешите уведомления.
- Напоминание восстанавливается после перезагрузки телефона.

## Как включить
1. Главный экран → 🔔 (вверху справа).
2. Включите «Присылать напоминания», выберите время, нажмите «Сохранить».
3. Разрешите уведомления в системном окне.

Если уведомления не приходят, проверьте, что для «Ежедневника» в настройках телефона включены уведомления и приложению разрешена работа в фоне (автозапуск).
