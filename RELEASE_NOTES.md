# Ежедневник 2.0.1

Ставится поверх прошлой версии. Для работы базы в Firebase должны быть опубликованы правила Firestore.

## Добавлено
- **Общий сервер (Firebase):** вся бригада работает с одной базой — отметки, наряды и исполнители общие.
- **Вход по логину и паролю** (без почты). Экран входа при запуске.
- **Роли:**
  - Администратор — создаёт аккаунты и назначает роли (кнопка 👥 вверху).
  - Начальник — только просмотр и скачивание отчётов.
  - Инженер и Сотрудник — отмечают работы, заполняют карточки (наряд, исполнители).
- **Аккаунт** (кнопка 👤): логин, роль, выход.

## Изменено
- Данные теперь синхронизируются между телефонами (обновляются при открытии дня/раздела), а не хранятся только на одном.
- У роли «Начальник» отметки и редактирование заблокированы (только просмотр).

## Как начать
1. Войти администратором: логин **admin**, пароль из Firebase.
2. 👥 «Пользователи» → создать аккаунты бригады с ролями.
3. Раздать логины — каждый входит и видит общую работу.

Уведомления, журнал Excel и карточки объектов — как раньше.
