# Ежедневник

Android-приложение для учёта работ: регламент, заявки и наряды по системам АПС, АОС, видеонаблюдение, ГГС и СКУД.

## Как получить APK

1. После каждого изменения GitHub сам собирает приложение (вкладка **Actions**, сборка «Сборка APK»).
2. Готовый файл появляется в **Releases** (справа на главной странице репозитория): скачайте `Ezhednevnik-1.0.N.apk`.
3. Откройте файл на телефоне и разрешите установку из этого источника.

Новые версии ставятся поверх старой, отметки сохраняются.

## Где хранятся данные

- Галочки хранятся во внутренней памяти приложения на телефоне.
- Отчёты Excel сохраняются в папку **Загрузки/Ежедневник**.
- В первые 7 дней нового месяца отчёт за прошлый месяц сохраняется автоматически.

## Структура

- `app/src/main/assets/www/` — интерфейс приложения (HTML/JS), логотип и фон.
- `app/src/main/java/.../MainActivity.java` — оболочка Android (WebView) и сохранение файлов.
- `.github/workflows/build.yml` — автоматическая сборка APK.
